# Anamaria

A beautiful, interactive web page created as a personal tribute. It features a digital candle that, when extinguished, triggers a blooming flower animation and a heartfelt message.

## ✨ Features

- **Interactive Candle:** Tap or click the candle to extinguish the flame.
- **Blooming Animation:** Smooth transition to a blooming flower garden effect.
- **Responsive Design:** Optimized for both desktop and mobile viewing.
- **Pure Web Technologies:** Built using only HTML, CSS, and Vanilla JavaScript.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3 (Animations), Vanilla JavaScript.
- **Styling:** Custom CSS with Keyframe animations for flickering flames and growing flowers.

## 🚀 How to Run

Simply open the `index.html` file in any modern web browser.
